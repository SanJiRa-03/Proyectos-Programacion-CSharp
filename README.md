# Portafolio de Proyectos y Desarrollo en C# (.NET)

¡Bienvenido/a a mi repositorio de desarrollo en C#! Este espacio está dedicado a consolidar y organizar mis soluciones de software, prácticas de programación orientada a objetos (POO), gestión de ficheros y algoritmos aplicados. El objetivo principal de este portafolio es asentar bases sólidas de arquitectura limpia, modularidad y buenas prácticas de desarrollo en el ecosistema .NET.

## 📂 Estructura del Repositorio

El repositorio está organizado por módulos independientes. Cada carpeta contiene el código fuente correspondiente junto con su propia documentación detallada:

* **01-Gestion-Embarcaciones-POO:** Sistema orientado a objetos para la administración y control de flotas de embarcaciones, aplicando jerarquías de clases y encapsulamiento.
* **02-Analisis-de-Texto-Romancero-Gitano:** Herramienta de procesamiento de texto inspirada en la literatura española, optimizada mediante LINQ, sanitización de puntuación y gestión eficiente de flujos E/S con `StreamReader`/`StreamWriter`.
* **03-Procesamiento-y-Filtrado-de-Datos-de-Sensores-IoT:** Aplicación robusta para la ingesta, auditoría estructural de 7 parámetros clave, aislamiento de anomalías y exportación limpia de lecturas de sensores en tiempo real.
* **04-Sistema-de-Gestion-de-Pedidos-Restaurante-POO:** Sistema interactivo de consola para comandas que implementa herencia, polimorfismo, composición y colecciones dinámicas para gestionar menús personalizados (*Estándar*, *Foddie*, *Light*) y actualización de estados.

## 🛠️ Tecnologías y Conceptos Clave

A lo largo de los diferentes proyectos se aplican los pilares fundamentales de C# y la ingeniería de software:

* **Programación Orientada a Objetos (POO):** Diseño de clases abstractas, herencia, composición de objetos y polimorfismo avanzado para reutilización y escalabilidad del código.
* **Gestión de Ficheros y E/S (Input/Output):** Lectura y escritura masiva de datos estructurados, validación de existencia de rutas y control de excepciones en tiempo de ejecución.
* **Manipulación de Colecciones y LINQ:** Uso intensivo de `List<T>`, filtrados avanzados, conteo de ocurrencias y procesamiento optimizado de estructuras de datos en memoria.
* **Clean Code y Modularidad:** Separación estricta de responsabilidades entre la interfaz de consola (`Program.Main()`) y las clases de lógica de negocio, aplicando constructores parametrizados y manejo de estados mediante enumeraciones (`enum`).

Proyectos desarrollados con enfoque en robustez, mantenibilidad, principios de arquitectura limpia y buenas prácticas de codificación.
