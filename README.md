# Portafolio de Proyectos y Desarrollo en C# (.NET)

¡Bienvenido/a a mi repositorio de desarrollo en C#! Este espacio reúne proyectos y prácticas de programación orientada a objetos (POO), gestión de ficheros, procesamiento de datos y desarrollo de aplicaciones. El objetivo es consolidar conocimientos de C# y .NET mediante soluciones modulares y documentadas.

El repositorio sigue creciendo: empezó con proyectos de consola y ha ido incorporando aplicaciones de escritorio, trabajo en equipo y, en las últimas carpetas, una colección de prácticas pequeñas para afianzar los fundamentos.

## 📂 Estructura del repositorio

El repositorio está organizado por proyectos independientes. Cada carpeta contiene el código fuente correspondiente y, cuando aplica, documentación adicional (README, presentación o memoria).

* [01-Gestion-Embarcaciones-POO](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/01-Gestion-Embarcaciones-POO): sistema orientado a objetos para administrar y controlar flotas de embarcaciones, aplicando jerarquías de clases y encapsulamiento.
* [02-Analisis-de-Texto-Romancero-Gitano](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/02-Analisis-de-Texto-Romancero-Gitano): herramienta de análisis de texto que trabaja con LINQ, tratamiento de puntuación y operaciones de entrada y salida con `StreamReader` y `StreamWriter`.
* [03-Procesamiento-y-Filtrado-de-Datos-de-Sensores-IoT](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/03-Procesamiento-y-Filtrado-de-Datos-de-Sensores-IoT): aplicación para procesar y filtrar datos de sensores, validar parámetros, detectar anomalías y exportar lecturas.
* [04-Sistema-de-Gestion-de-Pedidos-Restaurante-POO](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/04-Sistema-de-Gestion-de-Pedidos-Restaurante-POO): sistema de consola para gestionar pedidos de restaurante mediante herencia, polimorfismo, composición, colecciones `List<T>` y enumeraciones (`enum`).
* [05-Juego-de-Hundir-la-Flota-CSharp-POO](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/05-Juego-de-Hundir-la-Flota-CSharp-POO): juego de consola de Hundir la Flota desarrollado con C# y .NET Framework 4.8. Incluye tablero de 12 × 12, modos de juego, tipos de barco y gestión de partidas y resultados mediante ficheros de texto. Se acompaña de presentación y memoria del proyecto.
* [06-Juego-de-Simon-Says-CSharp-Windows-Forms](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/06-Juego-de-Simon-Says-CSharp-Windows-Forms): versión de Simon Says para escritorio, desarrollada con C# y Windows Forms sobre .NET Framework 4.8. Incluye pantalla de inicio de sesión, registro de usuarios, secuencias de cuatro colores y almacenamiento de cuentas en `usuarios.txt`. Al ser una práctica individual, incluye una memoria redactada por mí, además del README individual y la presentación.
* [07-Sistema-de-Gestión-de-Ventas-CSharp-Windows-Forms](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/07-Sistema-de-Gesti%C3%B3n-de-Ventas-CSharp-Windows-Forms): aplicación de escritorio desarrollada con C# y Windows Forms para gestionar un catálogo básico de productos. Permite añadir productos a una tabla, consultar sus datos al seleccionar una fila, editar la información y eliminar registros. Los campos incluyen número de producto, código de barras, denominación, precio y stock.
* [08-Tienda-Electrodomesticos-Herencia](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/08-Tienda-Electrodomesticos-Herencia): tienda de electrodomésticos de consola con una clase base `Electrodomestico` y cuatro clases derivadas (lavadora, lavavajillas, nevera y horno). Permite añadir productos, listarlos, ver los descatalogados y filtrar por marca.
* [09-Catalogo-de-Astros](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/09-Catalogo-de-Astros): catálogo de consola de estrellas, cometas y planetas organizado en una jerarquía de herencia a partir de la clase `Astro`.
* [10-Gestor-de-Contenidos](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/10-Gestor-de-Contenidos): proyecto en equipo para gestionar películas, series (con episodios) y podcasts. Incluye registro e inicio de sesión de usuarios, búsqueda por título, filtrado por tipo, sistema de likes y almacenamiento de datos en ficheros de texto.
* [11-Examenes-POO](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/11-Examenes-POO): tres ejercicios de examen que combinan jerarquías de clases, menús de consola y persistencia en ficheros: biblioteca de materiales, tienda de instrumentos (con alquiler) y deportistas.
* [12-Ejercicios-de-Practica](https://github.com/SanJiRa-03/Proyectos-Programacion-CSharp/tree/main/Proyectos-Programacion-C%23/12-Ejercicios-de-Practica): trece ejercicios cortos para practicar herencia, clases abstractas, composición, colecciones y ficheros (animales, vehículos, recetas, concesionaria, biblioteca de archivos, frutería, etc.). Incluye los enunciados de dos de ellos.

## 🛠️ Tecnologías y conceptos clave

* **C# y .NET Framework**: desarrollo de aplicaciones de consola y escritorio.
* **Programación Orientada a Objetos**: diseño de clases, abstracción, clases abstractas, encapsulamiento, herencia, composición y polimorfismo cuando corresponde al proyecto.
* **Colecciones y algoritmos**: listas (`List<T>`), recorrido de secuencias, búsqueda, filtrado y validación de datos.
* **Gestión de ficheros y E/S**: lectura y escritura mediante `StreamReader` y `StreamWriter`, y persistencia sencilla en ficheros de texto cuando el proyecto lo implementa.
* **Gestión de errores**: uso de `try/catch` y validación de las entradas del usuario.
* **Interfaces y eventos**: formularios de Windows Forms, controles `DataGridView` y gestión de eventos de botones y ratón.
* **Gestión de datos**: altas, consulta, modificación y eliminación de registros en aplicaciones de escritorio.
* **Modularidad y mantenibilidad**: separación de responsabilidades entre formularios, clases de datos y lógica de aplicación.
* **Trabajo en equipo y documentación**: proyectos colaborativos, READMEs, presentaciones y memorias.

## ▶️ Cómo abrir los proyectos

1. Abre el archivo `.sln` de la carpeta del proyecto con Visual Studio.
2. Compila y ejecuta con **F5**.
3. Los ficheros de datos (`.txt`) se crean automáticamente junto al ejecutable la primera vez que se usan.

Proyectos desarrollados con enfoque en aprendizaje continuo, modularidad, mantenibilidad y buenas prácticas de programación en el ecosistema C# y .NET.
